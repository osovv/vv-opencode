# Patterns: defects above and at the word level

A pattern is a candidate, not a verdict: apply the pass condition, check the exception, then edit within the mode's permissions. Humans under deadline and non-native writers produce the same shapes, so this catalog is not evidence of authorship and must never be reported as one. Each entry lists pass condition → fix → exception.

## Structure and argument (both languages)

1. **Late thesis.** Pass: the change, decision, or finding appears after background the reader does not need first. Fix: move it up (restructure mode; in copyedit, flag). Exception: tutorial order that teaches before concluding.
2. **Heading echo.** Pass: the first paragraph restates the heading with no new information. Fix: delete it, or replace it with the actual content. Exception: a lead-in that adds scope or audience.
3. **Strawman objection.** Pass: the text refutes a position nobody stated ("some might say X is overkill, but…"). Fix: delete, or state the real tradeoff from the source. Exception: a documented objection that was actually raised — cite it.
4. **Empty significance closer.** Pass: sections end with the same "why this matters" wrapper adding no fact. Fix: delete; if the significance is real, state the consequence once, where it belongs. Exception: a genuine consequence statement with content.
5. **Inflated authority.** Pass: "experts believe", "it is widely known" with no source; a routine change described as pivotal. Fix: state the actual effect, or cite; otherwise drop the claim. Exception: an attributed quotation (protected).
6. **Template formatting.** Pass: bold on every other phrase, forced triads, identical scaffolding regardless of content. Fix: emphasis only where the reader must not miss something; structure follows content. Exception: a project template that is the house style (level C).
7. **Chat leftovers.** Pass: "Great question", "I hope this helps", "As of my last update" inside an artifact. Fix: delete. Exception: none in artifacts; in dialogue, proportionality governs, not this catalog.
8. **Synonym cycling.** Pass: one concept renamed across sentences (client/service/component) without distinction. Fix: one term per concept. Exception: genuinely different referents, or an alias defined once.

## English word-level

Patterns here include nominalization chains, filler openers, hedge stacks, and inflated verbs.

9. **Nominalization chains.** Pass: "perform validation of", "make a decision". Fix: "validate", "decide". Exception: the noun is the term ("the validation" as a named stage).
10. **Filler openers.** Pass: "It is important to note that", "It should be mentioned that". Fix: delete the opener. Exception: none — but the clause after it must survive intact, hedges included.
11. **Hedge stacks.** Pass: "could potentially possibly". Fix: one honest hedge. Exception: a single meaningful hedge stays (see references/fidelity.md); legal and normative formulas stay.
12. **Inflated verbs.** Pass: "serves as", "boasts", "features" where "is" or "has" loses nothing. Fix: use the plain verb. Exception: derive the verb from the mechanism — "is used" does not replace "wins" when the sentence is about precedence.

## Русский язык (применять к русской прозе)

Основные семейства — канцелярит, отглагольные цепочки, канцелярские связки и дублированные оговорки.

13. **Канцелярит.** Условие: «осуществляет проверку», «производит запись», «в целях улучшения». Исправление: «проверяет», «записывает», «чтобы улучшить». Исключение: юридические и нормативные формулы, где оборот — термин.
14. **Отглагольные цепочки.** Условие: «для обеспечения возможности выполнения выгрузки». Исправление: «чтобы можно было выгрузить» (точнее — по источнику). Исключение: имя процесса-термина («выгрузка» как название операции).
15. **«Является», «данный», «имеет место».** Условие: «X является причиной Y», «данный файл», «имеет место потеря данных». Исправление: «X — причина Y» (причинность должна быть в источнике), «этот файл» или просто «файл», «данные теряются». Исключение: «является» в определении термина может остаться.
16. **Пассив без деятеля, когда деятель известен.** Условие: «было принято решение». Исправление: «команда решила» — только если деятель назван в источнике. Исключение: деятель неизвестен — не выдумывать.
17. **Дублированные оговорки.** Условие: «в некоторых случаях может наблюдаться потеря данных». Исправление: «иногда теряются данные» — оговорка сохранена, дублирование снято; условия неизвестны — пометить, не додумывать. Исключение: нормативная двойная оговорка как термин.

## Using this catalog

- Audit mode: report findings with pass-condition evidence and a minimal fix, marked by level (A meaning, B clarity, C project style).
- Draft self-check: run entries 1–8 once before delivery.
- Do not open this file end-to-end for a two-line copyedit; go to the specific entry you suspect.
